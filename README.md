# 🔎 ResearchMate

**ResearchMate** is a smart web research assistant designed to help users search topics, discover useful sources, and keep track of recent searches in one place.

## 🚀 Features

* Search research topics through a simple web interface
* Display multiple research results
* Show source information and snippets
* Open research sources in a new tab
* Store recent searches in browser local storage
* Re-run previous searches with one click
* Clear individual search results
* Clear complete search history
* Loading and error states
* Responsive design for desktop and mobile

## 🛠️ Tech Stack

### Frontend

* HTML5
* CSS3
* JavaScript

### Backend

* Node.js
* Express.js
* CORS
* dotenv

## ▶️ Run the Project Locally

### 1. Start the Backend

Open PowerShell and run:

```powershell
cd "C:\Users\Hi Users\Documents\ResearchMate\backend"
node server.js
```

The backend should run at:

```text
http://localhost:5000
```

### 2. Start the Frontend

Open another PowerShell window and run the frontend server from the `frontend` folder.

The frontend should be available at:

```text
http://localhost:5500
```

Open that address in your browser.
